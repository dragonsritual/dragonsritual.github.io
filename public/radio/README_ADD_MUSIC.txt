DRAGON RADIO — QUICK ADD MUSIC

1. Put approved MP3/M4A/OGG files in: public/radio/audio/
2. Optional artwork goes in: public/radio/artwork/
3. Add each track to public/radio/library.json in play order.

Example:
{
  "station": "Dragon Radio",
  "tracks": [
    {
      "title": "Track Name",
      "artist": "Artist Name",
      "type": "INDIE",
      "src": "/radio/audio/track-name.mp3",
      "artwork": "/radio/artwork/track-name.jpg"
    },
    {
      "title": "Dragon Break 01",
      "artist": "DragonsRitual",
      "type": "STATION BREAK",
      "src": "/radio/audio/dragon-break-01.mp3"
    }
  ]
}

IMPORTANT: Only upload audio you have permission/license to publicly stream. Keep written permission and source details.
