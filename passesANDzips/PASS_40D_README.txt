DRAGON GAMING — LEGIBILITY PASS 40D

Built directly on WORLD EVENT PASS 40C.

WHY
The Gaming Lounge looked strong, but important copy had drifted too small (often 5–8px).
This pass keeps the dense old-RPG / underground visual identity while raising functional
text to a comfortable reading floor.

WHAT CHANGED
- Body copy raised to ~12–13px
- Important labels raised to ~7–8px
- Navigation and buttons raised
- Realm Wire made easier to scan
- World Boss strip made easier to read at a glance
- World Boss detail page body/lore/combat copy enlarged
- Media mini-player controls enlarged slightly
- Mobile minimum type increased further

DESIGN RULE
Decorative microtext can stay tiny.
Anything the member needs to actually read, decide on, or click should not be microscopic.

INSTALL
Copy this pass into the current site repo and replace/merge matching files.
