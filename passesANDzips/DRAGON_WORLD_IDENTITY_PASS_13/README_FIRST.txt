DRAGON WORLD IDENTITY — PASS 13

WHAT THIS PASS DOES
- Removes the generic "Current." and "Final." presentation.
- Reframes the home feed as THE SIGNAL.
- Turns the sports area into a much larger, readable SCORE WIRE.
- Keeps spoilers OFF by default using the existing Pass 12 behavior.
- Pushes the visual language away from polite website cards and toward a living publication/network.
- Begins reframing Dragon TV as a network for games, creators, live art, interviews and events.
- Includes dedicated mobile overrides; mobile is not an afterthought.

INSTALL
1. Put this whole folder in the dragonsritual.github.io project root.
2. Stop npm run dev with Ctrl+C.
3. In PowerShell from the project root:
   Set-ExecutionPolicy -Scope Process Bypass
   .\DRAGON_WORLD_IDENTITY_PASS_13\APPLY_WORLD_IDENTITY_PASS_13.ps1
4. Run:
   npm run build
   npm run dev

The installer creates a timestamped backup under .migration-backups before changing files.
