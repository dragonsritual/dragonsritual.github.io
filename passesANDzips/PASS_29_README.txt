DRAGONSRITUAL — PASS 29
DRAGON TV: VIEWER FIRST

PURPOSE
Dragon TV now has two different mental models:

PUBLIC /tv/
A television experience. No analytics tabs, business dashboard, configuration panels or creator clutter.
- large channel preview
- ON AIR / free-to-watch language
- simple program guide
- channel cards
- creator discovery rail
- archive / vault
- one quiet creator entry point
- mobile-first responsive layout

CREATOR /creator/tv/
A separate business/production room.
Foundation cards for:
- Go Live
- Programming
- Audience
- Analytics
- Library
- Business / future subscriptions

This is intentional: viewers watch; creators operate.

FUTURE SUBSCRIPTIONS
Do not make subscription logic specific to TV. Build a shared creator entitlement/subscription system later so a streamer, writer, illustrator, group, etc. can offer audience memberships. Dragon TV can consume that system.

IMPORTANT
Buttons that need real streaming/follow/subscription backend are visual foundations only. This pass does not fake those systems.

INSTALL
Copy this ZIP into the current repository root preserving folders.
npm run dev
Check:
http://localhost:4321/tv/
http://localhost:4321/creator/tv/

NO SQL REQUIRED.
