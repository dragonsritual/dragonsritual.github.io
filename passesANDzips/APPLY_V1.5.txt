APPLY:
1. Stop Astro/Sanity with Ctrl+C if either terminal is actively running.
2. Back up your current dragonsritual.github.io folder if desired.
3. Extract this ZIP over:

      npm install

      npm run dev

      http://localhost:4321/journal/
