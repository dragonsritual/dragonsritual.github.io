DRAGON WORD OF THE DAY — PASS 39A

Adds a compact magazine-style WORD OF THE DAY card to DAILY.

WHY HERE
DAILY is the best public-facing place for a small daily ritual like this: it gives returning
members one more changing detail without turning the site into a utility dashboard.

FEATURES
- Changes once per calendar day.
- 31-word curated local lexicon; no API key, no network dependency, no ad/tracker.
- Word, pronunciation, part of speech, definition, example sentence.
- Browser speech button.
- Copy word button.
- Mobile responsive.
- Designed to fit the Dragon magazine / underground editorial language.

FILES
src/pages/index.astro
src/components/WordOfTheDay.astro
src/styles/word-of-day.css

INSTALL
Copy this pass over the current DragonsRitual repo and replace matching files.

NOTE
This is a delta pass intended for the current repo you already have locally.
