# DragonsRitual v1.5 — Public Journal

Public routes:

- `/journal/`
- `/journal/[slug]/`

The Journal now reads published Article documents directly from the
DragonsRitual Sanity project (`5dooc6p7`, dataset `production`).

## Included

- public Journal landing page
- generated article routes for published Sanity documents
- hero media from the shared DragonsRitual Media/Supabase URLs stored in Sanity
- rich Portable Text rendering for paragraphs, h2, h3, blockquotes and common marks
- author, publication date, categories and tags
- SEO title/description, canonical override, no-index and social hero image support
- optional resolution of related Supabase Game / Session IDs
- latest Journal dispatches on the Gaming homepage
- Journal added to the global site rail only now that it is a real public function

## Publishing workflow

1. Run `npm run newsroom`.
2. Write and publish an Article in Sanity.
3. Run/deploy Astro.
4. The published article appears on `/journal/` and receives its own route.

The current GitHub Pages deployment is static, so a new Sanity publication
becomes public on the deployed site after the Astro site rebuild/deploys.
During `astro dev`, requests read current Sanity data as the page is rendered.
