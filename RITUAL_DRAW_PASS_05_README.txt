DRAGONSRITUAL ARCADE BATTLE — PASS 05 — THE RITUAL DRAW

THIS MODIFIES THE ACTUAL ITCH.IO ARCADE BATTLE GAME.

CORE RULE: THE RUN IS THE BOOSTER.
- No pre-run character choice.
- Three combatants are automatically pulled from the registered fighter archetypes.
- Duplicate classes are allowed.
- Each pull rolls Common / Uncommon / Rare / Legendary / Mythic.
- Each pull rolls Fire / Water / Forest / Frost / Thunder / Air / Blood / Void.
- Characters may be named or title-based depending on rarity/luck.
- Higher rarities can carry additional rules text.

RUN REWARDS
- The old three-choice boon shop is removed.
- Each cleared wave reveals ONE card from the run's pre-generated reward deck.
- It can be a Ritual effect or Artifact.
- Artifacts have Weapon / Armor / Charm slots and are assigned to one surviving fighter.
- You may leave an artifact behind, but you cannot reroll the draw.

CHARACTER INSPECTION
- Click a fighter when not selecting a target.
- Inspect name, rarity, affinity, HP/ATK/DEF/SPD/crit/dodge, rules text and equipment.

COLLECTION
- COLLECTION records cards encountered across runs using localStorage.
- It records discoveries and repeat sightings, not permanent run power.
- A past Mythic becomes part of your archive/history but cannot simply be injected into the next run.

SCALING
- Card identity is compositional: archetype + rarity + affinity + name/title + rules text.
- The system can therefore represent enormous numbers of distinct cards without hardcoding one million JavaScript objects.
- The current ZIP only contains 3 player art archetypes; new purchased/licensed character packs should be added to the registry later.
